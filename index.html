Features

Everything you need for fast, private semantic search inside Obsidian.

Semantic & Hybrid Search

Search notes by meaning using cosine similarity, optionally blended with keyword matching (0% to 100% weight).

Search Filters

Narrow down results directly in the search bar using path:Folder/ and #tag.

Related Notes Sidebar

A dedicated sidebar view that automatically updates with related notes as you switch between files.

Embedding Profiles

Save, edit, and switch between Ollama, OpenAI, and LM Studio profiles. Each profile keeps its own index file.

Batching & Parallelism

Configure embedding batch size (1-64 chunks per request) and parallel workers (1-20), with cancel support.

Automatic i18n

Automatically adapts to your Obsidian language setting (English and German, with English fallback).

Installation

Build from source and copy the plugin files into your Obsidian vault.

1. Build the Plugin

git clone https://github.com/johannjdk/obsidian-semantic-embedding-search.git
cd obsidian-semantic-embedding-search
npm install
npm run build

2. Install in Obsidian

Copy the contents of dist/ into your vault's plugin folder: .obsidian/plugins/semantic-embedding-search/

  • dist/main.js
  • dist/manifest.json
  • dist/styles.css

Frequently Asked Questions

Does it work completely offline?

Yes. With Ollama or LM Studio running locally, no note content ever leaves your machine.

Where is the index stored?

Each embedding profile stores its own JSON index inside your vault's plugin directory.
